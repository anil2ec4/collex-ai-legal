# @collex/control-plane

Node/TypeScript research control-plane for ColleX (Master Build Brief 6.3B).
It owns request validation, capability selection, budgets/policy, research-run
state, evidence verification and the v1 HTTP API. It never talks to upstream
legal databases directly — all provider traffic goes through the Python
FastMCP gateway via `HttpMcpGateway`.

## Layout

- `src/capabilities/` — brief-6.5 typed contracts (`types.ts`), the frozen
  54-tool -> 7-capability registry (`registry.ts`), provider policies
  (`policy.ts`, brief 6.6).
- `src/retrieval/` — Turkish search normalization (brief 8.4), exact reference
  parser (LAW/ARTICLE/E-K regexes + false-positive guards), pure RRF mirroring
  the brief-8.6 SQL.
- `src/evidence/` + `src/verification/` — EvidenceRef/ClaimDraft (brief 9.2),
  deterministic citation validator (brief 9.3) using the project's canonical
  offset policy (**Unicode code point offsets into NFC text**, not UTF-16),
  finalization policy + verdicts (brief 9.4).
- `src/orchestration/` — budgets (brief 10.3) and the bounded executor
  (brief 10.4) with injected ports (RunStore/Planner/CapabilityExecutor/
  Verifier): budget-stop -> typed partial, idempotency replay, capability
  allow-list, authContext never sourced from planner output.
- `src/gateway/` — `ProviderGateway` + `FakeGateway` (tests) +
  `HttpMcpGateway` (JSON-RPC `tools/call` to `POST {baseUrl}/mcp/` with a
  Bearer token). **Unit-tested against a local mock only; not yet live-tested
  against the real Python server.**
- `src/api/` — hono v1 API (`/v1/health`, `/v1/search`, `/v1/research-runs`),
  OpenAPI 3.1 spec, example client, dev entrypoint.
- `fixtures/offset_policy.json` — cross-language offset fixtures, generated by
  `../scripts/gen_offset_fixtures.py`, also validated by
  `../tests/contracts/test_offset_policy.py` (Python parity).

## Commands

```bash
npm ci               # or npm install
npm run typecheck    # tsc --noEmit
npm test             # vitest run (fully offline)
npm run build        # tsc -> dist/
npm run dev          # build + start the v1 API on 127.0.0.1:8787
```

Dev server env: `PORT`, `MCP_BASE_URL` (default `http://127.0.0.1:8000`),
`MCP_API_TOKEN` (never logged).

## Invariants

- The registry maps **exactly the 54 offline MCP tools** (the invariant that
  `scripts/smoke_check.py` asserts); `search_bedesten_semantic` (conditional
  55th) is deliberately outside it.
- Response/contract evolution is additive-only.
- Offsets: Unicode code points into NFC canonical text; hashes: SHA-256 hex
  over UTF-8. Regenerate fixtures with
  `.venv/Scripts/python.exe scripts/gen_offset_fixtures.py` from the repo root.
