## 2. Contract AS IMPLEMENTED

### 2.1 Coverage gate — `control-plane/src/answer/coverage.ts` (new)

```ts
export const DEFAULT_COVERAGE_FLOOR = 0.4;
export type CoverageGate = "passed" | "failed" | "bypassed-by-reference";
export interface QuestionCoverage {
  ratio: number;              // weighted union coverage in [0,1]
  covered: string[];          // question words (as written) found in >= 1 passage
  missing: string[];          // question words found in no passage
  lexemes: string[];          // every content word of the question, as written
  passages: number;
  bestPassageCovered: number; // max distinct words one passage carries
  bestPassageIndex: number;   // -1 when no passages
}
export interface CoverageDecision extends QuestionCoverage { gate: CoverageGate; floor: number }
export interface QuestionCoverageReport extends CoverageDecision { setAside: number }

export function assessQuestionCoverage(question: string, quotes: readonly string[]): QuestionCoverage;   // contract [R]
export function decideCoverageGate(c: QuestionCoverage, o?: { floor?: number; referenceMatched?: boolean }): CoverageGate;
export function evaluateQuestionCoverage(question, quotes, o?): CoverageDecision;
export function referenceBypass(references: readonly ParsedReference[], hits: readonly { pinned: boolean }[]): boolean;
export function mapPassageCoverage(question: string, passages: readonly string[]): { lexemes: string[]; covered: number[][] };
export function stemTurkish(token: string): string;        // exported for tests
export function derivationalAlternate(stem: string): string | undefined;
export function lexemesMatch(a: string, b: string): boolean;
export function contentLexemes(text: string): string[];
```

Method (deterministic, offline): `normalizeTurkishSearch` → tokens on
`\p{L}\p{M}` → drop < 3 code points, numbers (split off), a Turkish stopword
list (connectives, question frames, auxiliaries, legal frame words such as
`hukuk/kanun/madde/fıkra/hüküm`, statute abbreviations, apostrophe case
suffixes) → conservative stemmer: up to 3 rounds of INFLECTIONAL suffixes
(case/possessive/plural/participle/passive/copula; bare vowels only in round
1; never below 3 code points, 4 for a bare vowel; stops at a known frame or
light-verb stem), final-consonant softening undone (`aracı` ≡ `araç`,
`dolandırıcılığın` ≡ `dolandırıcılık`). Matching: stem equality, or a shared
prefix of `max(4, ceil(0.7·min length))` on stems ≥ 4, plus a derivational
alternate (`değişiklik`→`değişik` meets `değiştirilmiştir`→`değiştir`).
`ratio` weights a word present in more than half of ≥ 4 passages at 0.5
("ceza" in a criminal corpus did not discriminate). **Gate**: bypassed when
the question cites a provision/decision AND a hit is pinned; otherwise passes
iff `ratio ≥ floor` AND one passage anchors ≥ 2 content words (or all of them
for a 1-word question). The anchoring rule is what defeats the audit shape
(two passages each contributing one word); it is documented as a deliberately
stricter reading of "ratio = covered / content lexemes".

### 2.2 Pipeline (`control-plane/src/pipeline/answerPipeline.ts`)


New trace stage `coverage` between `evidence` and `draft` (counts:
`lexemes, covered, passages, ratioPct, bestPassageCovered`; notes:
`gate=…`, `missing=…`). `rank` stage gains `counts.coverageSwaps` and
`COVERAGE_SWAP:<kept chunk>:<dropped chunk>` notes. On gate failure with a
non-empty pack: drafter skipped, verifier receives an EMPTY pack plus the
report → status `ABSTAIN`, reasons `QUESTION_NOT_COVERED` +
`ABSTENTION_NOT_FINALIZABLE`, warning `QUESTION_NOT_COVERED:<n>`, the n
passages in `contraryCoverage.observed` with reason `QUESTION_NOT_COVERED`,
`result.evidence = []`, `bundle.evidence = []`, `AnswerRun.pack` = the emptied
pack. Empty retrieval keeps `NO_EVIDENCE` (nothing was set aside).

## 6. Known gaps (honest)

- The gate is lexical. Two substantive shared words in one passage at ≥ 40%
  weighted ratio pass it. `fx-nearmiss-003` ("banka" + "kredi" in TCK m.158)
  is refused only by the ratio floor (33%); a shorter phrasing could pass.
  The rendered `Soru kapsamı` and the missing-word list are the reader's
  defence in that case.
- The eval driver measures the gate over the full ranked set; the product
  over its (now coverage-aware) top-8 pack. A cap-induced false abstention is
  therefore only visible through the real pipeline (§5), not the report. A
  later wave should add an answer-level eval that runs `AnswerPipeline`
  itself.
- The driver's trigram floor is 0.5 (search default); the answer route uses
  `DEFAULT_ANSWER_LIMITS` (0.35, perDocumentCap 4). Retrieval-level numbers in
  the report are therefore not the answer route's; the gate outcomes agree in
  every probed case.
- `questionCoverage` is not a sixth key inside `claims[].confidence` (frozen
  API test + Python exporter pin five). If a later wave widens both, the value
  is `result.coverage.ratio`.
- `origin: "live"` is reserved; this lane emits only `upload` / `corpus`.
- `demo.mjs` was not run (it recreates `collex_demo`); the probe in §5 covers
  its S1/S2/S3 questions through the same pipeline and adapters.
- Stopword/stemmer tables are hand-authored and Turkish-only; they should be
  re-measured on a real corpus before the 0.4 floor is treated as validated.
