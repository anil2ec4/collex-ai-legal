### HTTP

- `GET /v1/ai/status` → `{ configured, model: string|null, consent:'per-request', dataLeavesMachine:true, notes: string[] (TR), liveTested:false, provider:'anthropic', usage? }`.
- Every POST: `400 AI_CONSENT_REQUIRED` unless `useCloudAi === true` (JSON) / `'true'` (form); then `503 AI_NOT_CONFIGURED` when `config === null` (exact message above); then zod (`400 INVALID_REQUEST` + Turkish `issues`, unrecognized keys named in `path`).
- `POST /v1/ai/analyze-document {fileId, useCloudAi:true, focus?}` → `collex.ai.document-analysis/v1` (see AI.md §5): every list item `{text, evidence:[{chunkId, quote, dogrulandi, startChar?, endChar?}], kaynakli}`, `maddeler` only for `sozlesme`, `kaynaksizCount`, `itemCount`, `chunksAnalyzed/chunksTotal`, `warnings`, `disclaimer`, `usage`, `model`, `liveTested:false`. `404 NOT_FOUND` (no chunks), `503 STORE_UNAVAILABLE` (no files dep / store throws).
- `POST /v1/ai/ocr` multipart `{file, useCloudAi:'true'}` → guards before network: `413` (> 32 MB), `415` (no `%PDF-`), `413` (> 100 pages); `collex.ai.ocr/v1` `{fileName, pageCount, pages[{page,text}], text (\f-joined), warnings, provenanceHeader, model, usage, requests, upload:{fileName:'<name>.ocr.txt', text}, liveTested:false}`.
- `POST /v1/ai/draft-paragraph {draftId, sectionId, paragraphId?, insertAfter?, instructions, evidenceIds, useCloudAi:true, length?}` → `{draft, paragraph, entailment:[{evidenceId, score, entails, kept, rationale}], threshold:0.85, kaynakli, warnings, issues, model, usage, liveTested:false}`; `404` draft, `400` section/anchor/evidence, `503 DRAFTING_UNAVAILABLE` without `drafts`+`revise`.
- Adapter failure map: TIMEOUT→504 `AI_TIMEOUT`; NETWORK→502 `AI_UPSTREAM_UNAVAILABLE`; 401/403→502 `AI_AUTH_FAILED`; 429→503 `AI_RATE_LIMITED`; other HTTP→502 `AI_UPSTREAM_FAILED`; REFUSAL→502 `AI_REFUSED`; TRUNCATED→502 `AI_OUTPUT_TRUNCATED`; MALFORMED→502 `AI_MALFORMED_OUTPUT`.
