# Bağımsız Yargı + Mevzuat MCP

Bu klasör, `saidsurucu/yargi-mcp` ve `saidsurucu/mevzuat-mcp` projelerinden
türetilen, kişisel olarak barındırılabilen birleşik sürümdür.

Kurulum, yapılandırma, araç kapsamı, rate-limit ve güvenlik açıklamaları için
[`README-INDEPENDENT.md`](README-INDEPENDENT.md) dosyasını okuyun.
